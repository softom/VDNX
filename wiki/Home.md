# ВДНХ: исторический облик и смыслы

Вики-база исследования ансамбля **ВСХВ — ВДНХ — ВВЦ (1935–2024)**: планировка, фасады и смыслы,
заложенные в них.

**ВСХВ** — Всесоюзная сельскохозяйственная выставка (1935–1958), **ВДНХ** — Выставка достижений
народного хозяйства (с 1959), **ВВЦ** — Всероссийский выставочный центр (1992–2014). Прочие
сокращения — [Словарь терминов](Словарь-терминов.md#сокращения).

## Правила ведения вики

1. **Одна страница — один предмет.** Дублирование не допускается: факт живёт на своей странице,
   остальные ссылаются на неё.
2. **Факт и трактовка разделены.** Разделы «что построено» опираются на источники; разделы «что это
   значит» помечены как аналитика и могут оспариваться.
3. **Каждое фактическое утверждение снабжается ссылкой** на источник — прямо в строке или сноской
   в разделе «Источники» внизу страницы.
4. **Достоверность маркируется** по шкале A / B / C (см. [Источники](Источники.md#шкала-достоверности)).
   Всё, что помечено ⚠, нельзя переносить в публичные тексты без архивной проверки.
5. **Цитаты маркируются по типу:**
   - `[дословно]` — проверенный текст документа или публикации;
   - `[пересказ]` — изложение источника своими словами, дословность не гарантируется;
   - `[к сверке]` — цитата нужна, но подлинный текст пока не получен.
6. **Каждая правка датируется** в разделе «История страницы» внизу.

## Как перенести это в GitHub Wiki

Страницы названы по правилам GitHub Wiki (плоские имена, дефисы вместо пробелов, `Home`, `_Sidebar`,
`_Footer`), поэтому переносятся без переписывания:

```bash
# 1. Один раз включить вики: Settings → Features → Wikis, создать первую страницу через веб-интерфейс
git clone https://github.com/softom/VDNX.wiki.git
cp wiki/*.md VDNX.wiki/
cd VDNX.wiki && git add -A && git commit -m "перенос вики-базы" && git push -u origin master
```

Внутренние ссылки даны в виде относительных `.md` — они работают и в репозитории, и в GitHub Wiki.
