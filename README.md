# VDNX — исследование исторического облика ВДНХ

Репозиторий исследования: **исторический облик ВСХВ–ВДНХ–ВВЦ (1935–2024)** и **смыслы, заложенные
в планировках и фасадах**.

Задача исследования — не «краеведческая справка», а рабочая аналитическая база: понять, *как*
ансамбль устроен как высказывание (что и в каком порядке он сообщает посетителю), из каких слоёв
этот текст собран, какие слои были стёрты и какие восстановлены.

## Правила ведения

1. Одна страница — один предмет; дублирование не допускается.
2. Факт и трактовка разделены и помечены.
3. Каждое фактическое утверждение снабжается ссылкой на источник.
4. Достоверность маркируется по шкале **A / B / C**; всё с пометкой ⚠ нельзя переносить в публичные
   тексты без архивной проверки.
5. Цитаты маркируются: `[дословно]`, `[пересказ]`, `[к сверке]`.

Подробнее — [`wiki/Home.md`](wiki/Home.md#правила-ведения-вики).

## Перенос в GitHub Wiki

Страницы готовы к переносу без переписывания: включить вики (Settings → Features → Wikis), создать
первую страницу через веб-интерфейс, затем скопировать содержимое `wiki/` в клон
`VDNX.wiki.git`. Инструкция — в [`wiki/Home.md`](wiki/Home.md#как-перенести-это-в-github-wiki).
